# AI Resume Screening & Ranking System

A Python-based resume screening system that evaluates
candidates for an SDE internship requiring Python and
practical AI/agentic engineering experience.

## Features

- Batch PDF resume parsing
- Candidate information extraction
- Python and AI eligibility filtering
- Explainable candidate scoring
- Public GitHub activity enrichment
- Ranked JSON output

## Tech Stack

- Python
- PyMuPDF
- Pydantic
- GitHub REST API

## Setup

pip install -r requirements.txt

## Usage

python main.py --input ./resumes --output ./output/results.json
